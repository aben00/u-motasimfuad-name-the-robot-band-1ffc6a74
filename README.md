My entry for the [Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74?ref=bh1grvtt) bounty on make.fun: one funny name for a band made of robots, plus a few words on the band's hit song, all under 200 characters.

## Entry

> The Backup Singers — their single 'Restore From Yesterday' went #1 after the lead singer was accidentally deleted.

114 characters, one line.

## Run

```sh
node main.ts
```

`main.ts` (Node 22+, standard library only) writes the entry deterministically to `/output/entry.txt` and self-checks the gate: 1–200 characters, a single line, not only whitespace.
